# Munich 1972: an internal style test (not for publication)

The test: can the studio make a YouTube-documentary-style video (real archival photos and footage, 2.5D camera moves,
annotations, maps, kinetic type, a story told with feeling) instead of our paper-cutout styles? It is built with
HyperFrames (`/general-video`, companion flow). The user picked Munich 1972, 16:9, about 2–3 minutes; the story-led
rewrite runs 4:07.

**Internal only.** Many images and the archival footage are copyrighted (AP, Getty, the official 1972 film). The user
authorised them for this internal quality check only. They live in `assets/internal/`, which is git-ignored, and the
video is delivered privately, never on the public dashboard.

## How it's built

| Piece | Where |
|---|---|
| Brief | `BRIEF.md` |
| Design truth | `frame.md`; direction and documentary grammar in `DIRECTION.md` |
| Scene plan (10 scenes, cues by spoken word) | `STORYBOARD.md` (generated by `tools/build_storyboard.py`) |
| Script (27 paragraphs) | `script.json` (v1 kept in `build/script_v1.json`) |
| Narration | Fish S2.1 free, library voice Felix: `tools/vo.py` → `assets/vo.wav` + `timeline.json` (Whisper word times) |
| Score and SFX | code-synthesised: `tools/score.py` → `assets/score.wav`, `assets/sfx/` |
| Map | OpenStreetMap boundaries (Nominatim) → `assets/open/map-munich-ffb.svg`, pins in `data/mapmeta.json` |
| Scenes | `compositions/frames/s0.html` … `s9.html` (built by three parallel workers) |
