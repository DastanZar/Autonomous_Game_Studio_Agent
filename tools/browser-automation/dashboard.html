Browser

Agent window is a separate Chrome with its own profile (~/.agent-chrome). Open starts it as a normal, non-automated window so Google and others let you log in; log in once per site, tick "keep me signed in", then close that window (its ✕): closing it normally is what saves the login. The agent reuses those logins from then on. Auto uses your everyday Chrome if remote debugging is on, else the agent window. To use your own tabs: Chrome 144+, open chrome://inspect/#remote-debugging, switch it on, and click Allow when Chrome asks.
